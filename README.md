# One Line of Earned Pride

One line, a quiet earned moment of pride, written for the [Make.fun bounty](https://make.fun/bounty/u-mang-one-line-of-earned-pride-a0138557).

`main.py` writes the line to `/output/entry.txt`:

> The boy who stuttered through every reading lesson stood up at the town fair and read his own poem aloud, slowly, without stopping once.

Run it with `python3 main.py`.
